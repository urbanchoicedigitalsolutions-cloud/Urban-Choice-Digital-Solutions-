URBAN CHOICE WEBSITE
====================

Files:
- index.html: website structure and page content
- style.css: responsive white-and-purple design
- script.js: mobile navigation, year and WhatsApp enquiry form
- assets/urban-choice-logo.png: Urban Choice logo
- assets/urban-choice-intro.mp4: supplied introduction video

Preview:
Open index.html in a modern browser. Keep the assets folder beside it.

Publishing:
Upload the contents of this folder to the root of a GitHub repository, then enable GitHub Pages from the repository's Settings > Pages. The published URL will be provided by GitHub Pages.
